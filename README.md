# Mary PW Chin — Scientific career

Static website prepared for https://marypwchin.github.io/.

## Publish with GitHub Pages

1. Sign in to the **marypwchin** GitHub account.
2. Create or open the repository named **marypwchin.github.io**. If it already exists, review and preserve its existing files before replacing anything.
3. Upload `index.html` and `.nojekyll` from this package to the repository root. The schematic is embedded in the HTML; no separate image upload is required.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select **main** and **/ (root)**, then save.
7. Once deployment succeeds, visit https://marypwchin.github.io/.

No custom domain is needed. This package has not been uploaded or published.

To update the page later, replace `index.html` with the revised version.
